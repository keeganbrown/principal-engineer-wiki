# Quiz: Hero Culture

## What does a bus factor of one mean?

- [x] One person being unavailable could stall the project.
- [ ] Only one team owns the project.
- [ ] One incident per month is acceptable.
- [ ] The project has one deploy per week.

**Why:** The bus factor is how many people would need to be unavailable before a project stalls. See [[hero-culture]].

## Priya is the only person who can fix the reconciliation job. What change spreads the knowledge?

- [x] Next failure, someone else drives the fix while Priya only answers questions.
- [ ] Ask Priya to write a long wiki page and move on.
- [ ] Give Priya a bonus for every fix she makes.
- [ ] Move the job to a different team with no handover.

**Why:** Make the hero a teacher, not a fixer. It's slower the first time and spreads knowledge every time. See [[hero-culture]].

## Why can hero culture make the data look better than reality?

- [x] The hero fixes things before anyone logs them, so problems never reach a postmortem.
- [ ] Heroes falsify incident reports.
- [ ] Dashboards stop working when the hero is on call.
- [ ] Teams with heroes have fewer real incidents.

**Why:** Quiet rescues hide broken systems. Turn every rescue into a fix: a runbook, an alert, or a simpler system. See [[hero-culture]].
