# Quiz: Cargo Cult Engineering

## A 15-person team copies a 2,000-engineer company's split into hundreds of services. What do they get?

- [x] The operating cost, without the coordination problem the split solved.
- [ ] The same delivery speed as the large company.
- [ ] Simpler operations, since each service is small.
- [ ] Fewer incidents, since failures are isolated.

**Why:** The visible practice was the output of conditions the copier doesn't have. Find the problem it solved first. See [[cargo-cult-engineering]].

## A 30-person company adopts a big firm's eight-page design doc rule for every change. What fixed it?

- [x] A two-page doc only for work over two weeks or crossing teams, checked against data for a quarter.
- [ ] Making the template longer so docs are more complete.
- [ ] Dropping design docs entirely.
- [ ] Requiring two senior approvals on every doc.

**Why:** Adopt the principle, then pick the practice that fits your scale, and check whether you got the result. See [[cargo-cult-engineering]] and [[design-docs]].

## When is copying a practice without fully understanding it reasonable?

- [x] When it's cheap to try and easy to reverse, like a weekly demo for a month.
- [ ] When a famous company does it.
- [ ] When it's expensive to adopt but well known.
- [ ] Never; every practice needs full analysis first.

**Why:** For cheap, reversible practices you learn more by doing. Save scrutiny for practices that are expensive to adopt or hard to remove. See [[cargo-cult-engineering]].
